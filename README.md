# zubenelgenubi

**Smart contracts in Nazm.**

*Zubenelgenubi*, a claw of Libra, the scales — contracts weigh obligations.

## Status

**Planned — nothing here yet.** Smart-contract libraries and tooling. The toolchain already has a `contract` project template.

This repository is part of [Nazm](https://github.com/Nazm-Lang/nazm), a natively compiled
programming language with specified semantics. Nazm is at 0.9.0, a public preview of the 1.0
draft for macOS on Apple Silicon, with no compatibility promise until 1.0 — see
[nazm.dev](https://nazm.dev).
